# Player robot source

The original 64×160 transparent sheet and Piskel file are preserved here. The sheet contains two columns and five rows: Down, Up, Left, Right, Death; each row has two frames. All ten frames were losslessly separated into 32×32 PNGs in Assets/Project/Art/Sprites/Characters/PlayerRobot.

Unity settings match the existing enemy sprites: Sprite (Single), 32 pixels per unit, Point filtering, Clamp, no mipmaps, no texture compression, full rectangle mesh, centered pivot and transparent alpha.

This import prepares sprite assets. Animation clips and controllers are a separate step.
