# Enemy animation frames

Each colour has an editable Piskel file and a 608×32 PNG sheet containing nineteen 32×32 frames. The earlier nine-frame versions are in the parent folder.

Frame order, left to right:

- 1–8: Down, Up, Left and Right, two normal frames each.
- 9–16: Down, Up, Left and Right while scared, two frames each. The X stays in the centre.
- 17: white recovering frame.
- 18–19: dead frames with the side arms removed.

The sprites used in Unity are separate 32×32 PNGs under `Assets/Project/Art/Sprites/Characters/Enemies`.
